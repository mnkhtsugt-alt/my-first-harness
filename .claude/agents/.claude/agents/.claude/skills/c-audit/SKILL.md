# C Code Safety Audit Skill

## 목적
C언어 팩토리얼 코드의 안전성을 확인한다.

## 검사 항목
1. 재귀 함수를 사용하지 않았는가?
2. 음수 입력을 검사하는가?
3. 정수 오버플로우를 방지하는가?
4. 코드가 표준 C 문법을 따르는가?
5. 테스트 결과가 올바른가?

## 판정
- 모든 항목을 충족하면 PASS
- 하나라도 충족하지 못하면 REDO
- 문제점과 수정 방법을 구체적으로 기록한다.
